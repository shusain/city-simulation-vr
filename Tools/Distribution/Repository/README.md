# City Sim VR playtests

Download packaged playtest builds from this repository's **Releases** page. Choose the Windows ZIP under **Assets**, extract it completely, and open `Play-Desktop.cmd` or `Play-PCVR.cmd`. The automatic GitHub "Source code" downloads contain only these distribution documents and helpers, not the game.

This repository hosts tester instructions, release notes and feedback. Game source and editable assets are maintained separately. The downloadable game includes the cooked content required to play.

- [Getting started and controls](TESTING.md)
- [Known issues](KNOWN_ISSUES.md)
- Report a bug or suggest an improvement through **Issues**. Include the build ID from Windows `BUILD.txt` or the Quest APK filename.

These are early development playtests. Windows desktop and SteamVR PCVR share one Windows download. Quest standalone releases provide a separate named APK alongside the Windows ZIP; follow the sideload/update instructions in TESTING.md. Do not install the Windows download on a headset.

Development is moving quickly: old saves/assets may become incompatible and testers may need a new city. See release notes for intentional breaks.

Public repositories allow anyone to download published builds. A private repository requires each tester to have repository access.
