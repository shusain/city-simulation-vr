# Current playtest limitations

- This is a Development build for a small tester group. Broader balance, independent clean-machine/laptop coverage and minimum hardware remain unconfirmed.
- B001: a tester reports a black/blank screen on first launch that clears after relaunch. The cause and affected conditions remain unconfirmed; local cold-start checks do not establish a fix. Use the named Desktop launcher and report the release, entry file, exact prompt, hardware and first-attempt log if it happens.
- This release uses city format 67. Older city formats are unsupported; start a new city. Existing city/backup files remain intact and unsupported cities retain Archive/Restore. Keep copies and the matching older build if needed; migrations are deferred.
- The latest Desktop building appearance and condition indicators are user-accepted. Physical PCVR/Quest observations of current icons, art, music mix, text readability and specific logistics cases remain unconfirmed. Package validation is not a headset test.
- D3D11 is the supported Windows launch profile. Exclusive fullscreen, multi-monitor/DPI behavior and other hardware remain incompletely covered.
- Large cities can have CPU spikes; animated shadows can jitter. Formal frame/thermal/capacity measurements are deferred until needed. Desktop observations do not establish headset performance.
- Zoned growth checks every three game days; private construction and automatic density upgrades use private funds. City-funded roads, utilities, civic facilities, repairs and expansions cost the treasury. Broad difficulty and late-game costs remain provisional.
- Technology requires operating prerequisites, qualified paid staff, roads, utilities and upkeep. AI adoption, robotics and further economic branches are planned and absent from this build.
- The live inspector preview shows the static building body without separate animated visitors/attachments. Report clipped warnings, confusing controls or hover/resize issues.
- If a ground-level avenue utility connection issue recurs, include the current city save and a screenshot. Earlier catalog checks did not reproduce the report; no new fix is claimed.

Current traffic audio/distance and the relevant earlier Desktop/PCVR controls and soundscape reviews remain accepted. New headset content observations are separate. Preserve your cities and include the exact release/mode with feedback.
